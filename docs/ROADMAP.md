# PARTBASE Product & Engineering Roadmap

## Phase 1: Hyper-Local Foundation (Completed)
- [x] Hyper-local Chennai directory (OMR & Anna Nagar pilots)
- [x] Zero-fee policy validation and anti-scam checks
- [x] 3-strike community auto-hide moderation queue
- [x] Double-blind reciprocal rating system
- [x] Progressive Web App (PWA) manifest & offline caching
- [x] Comprehensive test suite (50+ unit and integration tests)

## Phase 2: Automation & Scaling (Upcoming)
- [ ] **WhatsApp Bot Notification Channel**: Real-time shift notifications sent to seekers via WhatsApp Business Cloud API.
- [ ] **UPI Autopay Escrow**: Micro-settlement escrow system ensuring guaranteed same-day worker payout upon shift QR scan.
- [ ] **Voice Shift Posting (Tamil & English)**: Audio-to-text job creation allowing local merchants to post shifts by speaking over phone.
- [ ] **Geofenced Shift Check-in**: Verification of candidate arrival within 100 meters of the merchant address using GPS geofence.
